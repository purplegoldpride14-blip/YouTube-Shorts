# Where the skill lives

The real skill is at `.claude/skills/nostalgia-shorts-pipeline/SKILL.md`.

Claude Code only auto-discovers skills inside `.claude/skills/<name>/`, so that
is where it has to sit. This file is here so anyone who goes looking for
`SKILL.md` at the root finds the pointer instead of nothing.

To run it: open this folder in Claude Code and type `/nostalgia-shorts-pipeline`,
or just describe what you want ("make me a new short") and it will load itself.
